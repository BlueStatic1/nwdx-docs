Overview

The Weather Radar is a block used to detect and show storms.

Crafting

Usage

once placed a black screen will appear above the block

and it will start showing the size and strength of the storm via cloud pixel color.

Notes

this block has 3 levels

level 1 only scans a 7 block radius

level 2 only scans a 22 block radius

level 3 only scans a 37 block radius

Known Bugs

this block only shows storms right above the block.
